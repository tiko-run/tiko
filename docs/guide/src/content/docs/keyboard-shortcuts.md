---
title: Keyboard shortcuts
description: Every tool and action has a key.
---

Press `?` in the app to see this list. `⌘` is `Ctrl` on Windows and Linux.

## General

| Keys | Action |
|---|---|
| `?` | Keyboard shortcuts |
| `⌘K`, `⌘F` | Search the board |
| `/`, `⌘K` | Find a board on [Home](../home/#find-a-board) |
| `⌘P`, `⌘⇧P` | Commands |
| `⌘Enter` | Select all search results |

## Tools

| Keys | Action |
|---|---|
| `V` | Select |
| `H` | Hand |
| `F` | Frame |
| `N` | Sticky note |
| `T` | Text |
| `S` | Shapes |
| `R` | Reminder |
| `C` | Task card |
| `M` | Modules |
| `Esc` | Back to Select |

## Edit

| Keys | Action |
|---|---|
| `⌘Z` | Undo |
| `⌘⇧Z`, `Ctrl+Y` | Redo |
| `⌘C` | Copy |
| `⌘X` | Cut |
| `⌘V` | Paste at the cursor |
| `⌘D` | Duplicate |
| `⌘A` | Select all |
| `Delete`, `Backspace` | Delete selection |
| `Shift` + click | Add to selection |

## Canvas

| Keys | Action |
|---|---|
| `Space` + drag | Pan |
| `Ctrl` + wheel, pinch | Zoom |
| `Shift` + wheel | Pan sideways when the wheel zooms |
| `Alt` + drag | Move without snapping |
| `B` | Back to where you were |
