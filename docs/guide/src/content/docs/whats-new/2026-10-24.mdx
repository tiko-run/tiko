## 💎 Improvements

- **Sharing:** Open an invite and sign in with the account you already have.
- **Demo:** The demo gives each visitor a sandbox of their own, Planning included, kept when they sign up.
- **Board:** The card tool shows what it accepts, with examples a click away.
- **Board:** Cleaner highlight when you select several lines of text.
- **Gantt:** Columns and timeline are easier to tell apart, and **+** extends the timeline by one step instead of a quarter.
- **Settings:** Choose whether task links open in a new tab.
- **Sign-in:** Someone guessing your password elsewhere no longer locks you out.
- **Guide:** A fresh look that's easier to scan. Copy any page as Markdown or ask ChatGPT or Claude about it.
- **Site:** A refreshed, more interactive tiko.run. Leave your e-mail to hear when tiko Cloud opens.

## 🐞 Fixes

- **Board:** Fixed the selection bar hiding behind the focus timer.
- **Board:** Fixed a stray focus ring in the welcome tour.
- **Trackers:** Fixed cards showing tasks from a token you had just replaced.
- **Trackers:** Fixed closed GitHub issues showing "Closed" instead of their status label.
- **Gantt:** Fixed a second click reopening a stage or time off menu instead of closing it.
- **Gantt:** Fixed month lines falling between weeks.
- **Gantt:** Fixed cramped task titles on boards that mix trackers.
- **Sharing:** Fixed Copy link doing nothing over plain HTTP.
- **Sharing:** Fixed GitHub cards on public boards losing their link.
- **Settings:** Fixed "Never signed in" for people who joined by invite.
- **Timers:** Fixed the focus timer flashing while the page loads.
- **Updates:** Fixed the backup taken before an upgrade not restoring the previous version.

<details>
<summary>🔧 Under the hood</summary>

- **Server:** tiko now runs on Postgres in a container of its own, so a busy team never waits on the database. The installer moves your data over. See [Coming from an SQLite release](/data-and-upgrades/#coming-from-an-sqlite-release).
- **Server:** Bring your own Postgres with `DATABASE_URL`. The Render blueprint includes one.
- **Server:** One-click updates back up the database first and roll back if something goes wrong.
- **Server:** Correct visitor addresses behind Railway, Cloudflare or nginx, so sign-in limits hit only the one who misbehaves. See [The client's address](/configuration/#the-clients-address).
- **Server:** Usage counts now include boards changed per week and the install OS. Still nothing personal.
- **Server:** tiko no longer trusts the compromised emSign ECC Root CA - G3 certificate.

</details>
