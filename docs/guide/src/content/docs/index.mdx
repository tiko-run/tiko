Put tasks in frames, circle a group, leave a sticky note beside it and draw arrows between them. Statuses update on their own while the board is open, so the board stays true without manual upkeep.

tiko is for people who keep a lot of work in their head and think spatially: leads, managers, anyone juggling tasks across projects. [Why we build it](why/) explains what tiko is for and how we decide what goes into it.

## What tiko is not

- The tracker stays the source of truth: tiko doesn't change status or edit tasks.
- Desktop only, English only.

The source code, issues and releases live on [GitHub](https://github.com/tiko-run/tiko). Questions and ideas go to [Discussions](https://github.com/tiko-run/tiko/discussions).
